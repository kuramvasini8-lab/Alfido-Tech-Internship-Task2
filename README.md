## Project Overview

This project is an interactive and responsive Quiz Application developed using HTML5, CSS3, and JavaScript. The application tests users' knowledge of web development concepts through multiple-choice questions with a circular countdown timer, instant answer validation, score tracking, and a modern dark-themed user interface.

---

## Features

* Welcome Screen
* Instructions Screen
* Multiple Choice Questions
* 10 Seconds Timer for Each Question
* Correct Answer & Wrong Answer Highlighting
* Automatic Score Calculation
* Result Screen with Marks Display
* Restart Quiz Functionality
* Responsive Design
* Modern Dark Theme Interface
* Dynamic Question Rendering using JavaScript DOM Manipulation

## How to Use

1. Download or clone the repository.
2. Open the project folder.
3. Modify the questions array in `script.js` to add, remove, or update quiz questions as required.
4. Customize styles in `style.css` if needed.
5. Open `index.html` in any modern web browser.
6. The application automatically updates question numbering, score calculation, and result display based on the total number of questions available.
